# 霓虹游戏厅 · NEON ARCADE

两个用键盘玩的小游戏，单文件、零依赖、不联网也能玩。

## 🎮 游戏

| 游戏 | 玩法 |
| --- | --- |
| **打字追缉** | 小偷在逃，敲对字母警察就往前冲。把距离追到 0 米抓住他，别让他跑出 100 米。3 条命。 |
| **打字赛车** | 敲字就是油门，和一台粉色对手车抢 700 米终点线。手一停就掉速，先冲线者赢。 |

## 怎么玩

打开页面 → 选一个游戏 → **点一下画面让键盘生效** → 开始。

- `A`–`Z` 输入单词
- `Backspace` 退格
- `Esc` 暂停
- `M` 静音

## 说明

- 纯前端：HTML + CSS + Canvas + WebAudio，没有构建步骤，没有任何外部请求。
- 两个游戏通过内嵌 iframe 运行，互不干扰。
- 最高分存在浏览器 `localStorage` 里，换设备不会同步。
- 手机浏览器能玩，但打字游戏建议用电脑。

## 部署

这个仓库就是 GitHub Pages 站点本身：`index.html` 在根目录，Settings → Pages 选 `main` / `(root)` 即可。
